# 🚀 Umar Ahamed — Portfolio Website

A futuristic, data-driven portfolio showcasing my work in **Data Science, AI/ML, Full-Stack Development, and Data Engineering**.

---

## 🔍 Overview

This portfolio is designed as a **modern, production-style web application** that highlights my projects, technical skills, and experience through an interactive and visually rich UI.

It combines:

* ⚡ High-performance frontend (React + Vite)
* 🎨 Futuristic UI design (Tailwind CSS + animations)
* 📊 Data-focused project showcase (BI, ML, Full-Stack)

---

## 🚀 Getting Started

### Clone the repository

```
git clone https://github.com/umar-ahamed-ds/umar-ahamed-portfolio.git
cd umar-ahamed-portfolio/frontend
```

### Install dependencies

```
npm install
```

### Run locally

```
npm run dev
```
